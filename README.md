# Capy Publisher Site

This is a simple, static, informational webpage for Capy Publisher.
It is designed to serve as the "Website URL" when registering Capy Publisher as a Seller App in Etsy Developer.

**Important Note:** This repository and website are completely independent of the main Capy Publisher application codebase.

## How to open locally

Simply double-click the `index.html` file to open it in your default web browser. Since it is a completely static HTML/CSS site with no external dependencies, it will work instantly without any build steps or local servers.

## How to publish via GitHub Pages

1. Create a public repository on GitHub (e.g., `capy-publisher-site`).
2. Push these files to the `main` branch of that repository.
3. In the GitHub repository settings, go to the "Pages" section.
4. Under "Build and deployment", select "Deploy from a branch".
5. Choose the `main` branch and the `/ (root)` folder, then save.
6. GitHub will build and deploy the site. Your site will be available at `https://<your-username>.github.io/capy-publisher-site/`.
