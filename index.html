Capy Publisher

Local desktop publishing workflow manager.

About

Capy Publisher is a private local desktop application used to organize product assets, metadata, and publishing workflows for my own online stores.

The application helps prepare product listings, manage images and digital files, and keep a local history of publication activity.

Etsy Integration

Capy Publisher uses Etsy's official API to manage my own Etsy shop.

The Etsy integration is designed to create draft digital listings and upload listing images and digital product files.

Etsy account authorization is performed through Etsy's official OAuth authorization flow.

Capy Publisher does not request or store Etsy account passwords.

Privacy

Capy Publisher is a local-first desktop application.

Project information and publishing history are stored locally on the user's computer.

Sensitive API credentials are not published on this website.

This website does not collect personal information, use cookies, or perform analytics.

Availability

Capy Publisher is currently a private tool used by its developer for their own publishing workflow.

It is not currently offered as a public SaaS service or marketplace application.
